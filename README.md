# Emotion Detection Application

Final project for **Developing AI Applications with Python and Flask** (IBM/Coursera).

## Project Name
**Emotion Detector** — AI-based web application that analyzes text and detects emotions using the IBM Watson NLP library.

## Description
This Flask web application accepts a text string from the user and returns emotion scores for anger, disgust, fear, joy, and sadness, along with the dominant emotion detected by the Watson NLP Emotion Predict API.

## Technologies
- Python 3
- Flask
- IBM Watson NLP (Embeddable AI)
- Requests
- Unittest
- Pylint
